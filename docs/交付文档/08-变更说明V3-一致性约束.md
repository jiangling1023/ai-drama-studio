## 二、迁移规则（逐行对照 `migrate()`）

v3 迁移段原文逻辑（`schema.js:146-161`）：

```js
// v2→v3：补 4 空集合 + 一致性约束锁定=true + 6 条一致性种子；不覆盖已有值，已有 consistencyRules 则保留（§2.2）
if (raw && raw.schemaVersion === 2) {
  if (!('一致性约束锁定' in raw)) raw.一致性约束锁定 = true;
  if (!Array.isArray(raw.shotDeconstructions))   raw.shotDeconstructions = [];
  if (!Array.isArray(raw.promptArchitectResults)) raw.promptArchitectResults = [];
  if (!Array.isArray(raw.reverseAnalyses))       raw.reverseAnalyses = [];
  if (!Array.isArray(raw.consistencyRules))      raw.consistencyRules = [ …6 条… ];
  raw.schemaVersion = 3;
}
```

**必须遵守的四条迁移原则：**

1. **不覆盖已有值**：所有赋值都带 `if (!(...))` 守卫。用户已改过的规则不会被种子数据冲掉。
2. **有则保留**：已有 `consistencyRules` 数组（哪怕为空数组 `[]`）时**不注入种子**——因为 `Array.isArray([])` 为真。这是有意的：用户主动清空过就别硬塞回来。
3. **默认锁定**：`一致性约束锁定` 默认 `true`，即新老工程默认开启一致性约束。
4. **高版本拒绝**：`schemaVersion > SCHEMA_VERSION` 直接抛错「工程文件版本高于当前工作台，无法导入」，**不静默降级**。

## 三、新增根字段：`一致性约束锁定`

| 项 | 值 |
|---|---|
| 类型 | `boolean` |
| 默认 | `true`（v3 迁移与新建工程均如此） |

即：**总开关开 → 全注入；总开关关 → 只注入单条已锁定的类别。**

## 五、负面提示词唯一并入点

这是 v3 最关键的实现约束。全项目**只有一个**函数负责把各类负面词合并（`prompt-builder.js:68-79`），F-006 / F-007 / F-010 / F-012 共用：

```js
export function assembleNegativePrompt(project, shotOrContext) {
  const neg = [];
  // ① 先入锁定词：具最高优先级，先 push
  if (project.promptSet?.负面词锁定状态 === '已锁定')
    neg.push(...(project.promptSet.锁定词快照 || []));
  // ② 再并入一致性表达：总开关开 或 单条锁定
  for (const r of (project.consistencyRules || []))
    if (project.一致性约束锁定 || r.全局锁定状态) neg.push(r.提示词表达);
  // ③ 最后并入单条负面词
  if (shotOrContext && shotOrContext.单条负面词) neg.push(...shotOrContext.单条负面词);
  // ④ 末尾去重：锁定词唯一，重复表达合并
  return [...new Set(neg)];
}
```

**三条不可违反的规则：**

1. **顺序即优先级**：锁定词先 push，靠末尾 `new Set` 去重时「先出现者胜」，所以锁定词永远不会被后面的东西覆盖。
2. **不许绕过**：任何模块要加负面词，只能走这个函数或往 `单条负面词` 里塞，**不得自行拼字符串**（否则一致性规则会漏注入，这是最难查的一类 bug）。
3. **锁定词只可追加**：`rejectLockedWordRemoval()` 对「移除/删除/去掉/排除/置空/清空/覆盖/注释/忽略/remove/exclude」等任何移除意图一律拒绝，返回 `该负面词已被全局锁定，不可移除`。

另外 v3 延续了 ANC 的「锚点覆盖」规则（`prompt-builder.js:36-42`）：单条正向词里若出现已锁定锚点的同类描述词，这些词会被**剔除**并记入 `被锚点覆盖` 字段——锚点优先级高于单条描述，冲突时以锚点为准且**不报错**。
