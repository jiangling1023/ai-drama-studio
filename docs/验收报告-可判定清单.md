## 剧本（F-001）

- [ ] 输入一句话创意后点生成，`剧本原文` 变为非空，`剧本来源` = 生成
- [ ] 导入 .txt 文本后 `剧本来源` = 导入，且原文逐字未改动（导入前后用查找比对同一段落）
- [ ] 诊断区显示旁白占比、台词覆盖率、动作描述密度三项数值，与 `DIAGNOSIS_CONFIG` 阈值一致（15 / 80 / 2 条 20 字）
- [ ] 总场次为 0 或文本为空时，诊断等级显示「不通过」并说明不计算比例
- [ ] 改写建议逐条给出「对象ID / 原句 / 建议替换 / 理由」四列，原句为原文逐字引用

## 资产（F-003 / F-004）

- [ ] 提取后 `assets` 条目数 ≥ 场次中出现的人物+场景+道具去重数量，每条均带来源文本片段
- [ ] 类型筛选「人物 / 场景 / 道具」切换后列表条目数变化，且不改变已落库资产数量
- [ ] 人物资产锁定后 `锁定状态` = 已锁定且 `锚点标识` 非空；解锁后回落未锁定
- [ ] 未锁定人物在后续提示词组装中不注入锚点，界面出现「角色 X 无有效锚点，不保证一致性」提示
- [ ] 锚点与单条同类描述冲突时，冲突词记入「被锚点覆盖」，最终提示词内只出现锚点版本

## 分镜（F-005）

- [ ] 生成后每条分镜均带 `场次ID`，无悬空场次引用（逐条核对场次列表存在性）
- [ ] 六要素校验逐条标出缺失项（景别 / 机位 / 运镜 / 左右方向 / 表情推进 / 转场）
- [ ] 台词字数超过时长折算上限时给出可读提示（2 秒 6 字 / 3 秒 9 字 / 4 秒 12 字）
- [ ] 分镜行内编辑保存后，重新进入该页数据仍在（刷新后一致）

## 图片（F-006）

- [ ] 点生成后该资产出现「进行中」任务卡片，完成后 `参考图引用` 非空
- [ ] 同一资产存在进行中任务时再次点击生成，不产生第二条进行中任务
- [ ] 未配置模型时任务状态为「已降级(演示数据)」，卡片显示实底「演示数据」角标
- [ ] 失败任务可点重试，`重试次数` +1，且不新增第二条任务
- [ ] 每张卡片可展开最终提示词快照与输入快照

## 画布（F-009）
