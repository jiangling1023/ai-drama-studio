# 功能说明 · 短剧工作台

一站式 AI 短剧工作台，纯前端零构建。全部模块共用一个 Project 对象（`js/schema.js` 的 `createEmptyProject()`），页面只读写该对象，不各自持有状态副本。

约定说明：

- **输入**列只列用户可见的输入源；**输出**列只列落在工程数据里的字段（UI 态不落库）。
- 所有生成类模块统一走 `core/gen-task.js`（创建任务 → 运行 → 写回状态 / 耗时 / 错误 / 降级原因），任务状态只在 `genTasks` 一处，界面多处同源展示。
- 未配置模型、配置未启用、勾选「强制演示数据」或调用失败，一律降级演示数据，界面标注「演示数据」，流程不中断。

## F-001 剧本

| 项 | 内容 |
| --- | --- |
| 输入 | 一句话创意（文本）、导入的剧本文本（.txt / .md）、生成按钮 |
| 处理 | 有创意时经统一模型出口生成剧本；导入时只做解析与诊断，不改写原文 |
| 输出 | `剧本原文`、`一句话创意`、`剧本来源`（生成 / 导入）、`scriptDiagnoses`（诊断结果与改写建议） |
| 关键规则 | 诊断固定三项口径：旁白占比 ≤15%（>30% 为不通过线）、台词覆盖率 ≥80%（<60% 不通过）、每场次动作描述 ≥2 条且 ≥20 字；阈值全部取自 `DIAGNOSIS_CONFIG`，界面不出现第二份数字；导入仅显示诊断结论，**不自动改写原文**，改写建议逐句列出原句与建议替换 |

## F-002 拆分剧本

| 项 | 内容 |
| --- | --- |
| 输入 | 剧本原文、拆分按钮、集/场次行内编辑 |
| 处理 | 按「第 N 集」「第 N 场」标记递归切分，无标记时按句子边界兜底；每场次保留来源文本片段便于回溯 |
| 输出 | `episodes`（集）、`scenes`（场次：地点 / 时间 / 出场人物 / 正文 / 来源文本片段） |
| 关键规则 | 拆分结果可逐行编辑；重新拆分属覆盖性操作，需一次显式确认，取消即零变更 |

## F-003 分解提取资产

| 项 | 内容 |
| --- | --- |
| 输入 | 场次正文、提取按钮、类型筛选（人物 / 场景 / 道具）、关键词 |
| 处理 | 从场次正文抽取人物、场景、道具，去重后落库；类型与关键词只影响展示，不影响已落库资产 |
| 输出 | `assets`（资产ID / 类型 / 名称 / 来源文本片段 / 外貌 / 服装 / 特征 / 锚点标识 / 锁定状态 / 创建序） |
| 关键规则 | 类型只允许人物 / 场景 / 道具三类；每条资产必须带来源文本片段，保证可回溯到原文 |

## F-004 人物锚点锁定（ANC）

| 项 | 内容 |
| --- | --- |
| 输入 | 资产列表、锚点标识编辑、锁定 / 解锁操作 |
| 处理 | 为人物资产生成或填写锚点标识（`ANC-*`），锁定后该锚点进入提示词组装链路 |
| 输出 | `assets[].锚点标识`、`assets[].锁定状态`（未锁定 / 已锁定） |
| 关键规则 | **ANC-01/02/04**：只有「已锁定 + 锚点标识非空」的人物才注入提示词，未锁定/无锚点不注入且不阻断后续步骤，界面提示「角色 X 无有效锚点，不保证一致性」；**ANC-03**：锚点优先级高于单条同类描述，冲突词记入「被锚点覆盖」且不生效 |

## F-005 分镜脚本

| 项 | 内容 |
| --- | --- |
| 输入 | 场次、生成按钮、分镜行内编辑（景别 / 机位 / 运镜 / 画面描述 / 对白 / 时长） |
| 处理 | 按场次生成分镜条目，并做六要素与台词时长校验 |
| 输出 | `shots`（分镜ID / 场次ID / 镜号 / 景别 / 运镜 / 画面描述 / 对白 / 时长 / 关联资产ID列表 / 关联关键帧ID列表 / 单条正向词 / 单条负面词） |
| 关键规则 | 六要素 = 景别、机位、运镜、人物左右方向、表情推进、转场，缺项逐条标出；台词字数上限按每秒 3 字折算（2/3/4 秒取固定档），超长给出可读提示；分镜必须绑定场次ID，悬空即判不可执行 |

## F-006 图片生成

| 项 | 内容 |
| --- | --- |
| 输入 | 资产（人物 / 场景 / 道具）、生成 / 重试按钮、仅看未生成筛选 |
| 处理 | 逐资产生成参考图，任务经统一出口执行，进行中按资产ID 保进度态 |
| 输出 | `assets[].参考图引用`、`genTasks`（状态 / 耗时 / 错误 / 重试次数 / 提示词快照） |
| 关键规则 | 同一资产存在进行中任务时不重复建任务；失败降级演示数据并标注九类降级原因之一；每张卡片可查看最终提示词快照与输入快照 |

## F-007 关键帧生成

| 项 | 内容 |
| --- | --- |
| 输入 | 分镜、帧类型（首帧 / 尾帧）、生成 / 重试按钮、仅看缺失筛选 |
| 处理 | 按分镜 + 帧类型生成关键帧，缺失判定由图片引用是否为空派生 |
| 输出 | `keyFrames`（帧ID / 分镜ID / 帧类型 / 图片引用）、`genTasks` |
| 关键规则 | 缺失帧是展示标记，不新增状态枚举；首帧 / 尾帧各自独立任务，互不覆盖 |

## F-008 提示词（NEG）

| 项 | 内容 |
| --- | --- |
| 输入 | 全局正向词、负面词、单条负面词、锁定 / 解锁操作、快照预览选择 |
| 处理 | 维护全局提示词组，锁定负面词生成只读快照；组装时锁定词 ∪ 一致性表达 ∪ 单条词去重 |
| 输出 | `promptSet`（组ID / 全局正向词 / 全局负面词 / 负面词锁定状态 / 锁定词快照 / 锁定时间 / 解锁时间） |
| 关键规则 | **NEG-02/04**：锁定词必定出现且去重，单条移除声明被忽略；**NEG-03/04**：对锁定词的移除 / 置空 / 覆盖 / 注释一律拒绝，只可追加；每条负面词可查看「最终提示词快照」复核实际生效内容 |

## F-009 画布生成（CNV）

| 项 | 内容 |
| --- | --- |
| 输入 | 指令输入框（三选一）、生成 / 重建按钮、节点行内编辑 |
| 处理 | 精确匹配三条指令后按数据源生成节点网格，节点与数据源条目一一绑定 |
| 输出 | `canvasNodes`（节点ID / 类型 / 关联数据ID / 标题 / 位置） |
| 关键规则 | **CNV-01**：只识别「按场次生成 / 按分镜生成 / 按资产生成」，其余指令一律不触发并给出格式提示；**CNV-02/03**：节点数 = 数据源条目数、一一绑定、每行 4 个网格布局；**CNV-04**：画布非空时重复提交须一次显式确认，确认后全量重建不叠加，取消零变更；**CNV-05**：空数据源不生成占位空节点；**CNV-06**：非法指令节点数不变；**CNV-07**：编辑/拖动不得改「关联数据ID」 |

## F-010 分镜成品

| 项 | 内容 |
| --- | --- |
| 输入 | 分镜、关键帧、提示词组、生成成品按钮、导出 |
| 处理 | 把分镜 + 关键帧 + 最终正/负面词合成成品条目，并做锚点与锁定词完整性校验 |
| 输出 | `storyboardItems`（成品ID / 分镜ID / 镜号 / 画面描述 / 关键帧图引用 / 对白 / 时长 / 最终正向词 / 最终负面词 / 关联锚点标识） |
| 关键规则 | 最终负面词 = 锁定词 ∪ 六类一致性表达 ∪ 单条词；缺锚点或缺失帧的条目标出但不阻断生成；支持按 JSON / CSV 导出（导出物不含密钥） |

## F-011 视频整合（VID）

| 项 | 内容 |
| --- | --- |
| 输入 | 分镜成品、片段顺序、导出配置（帧率 / 分辨率 / 输出命名规则 / 默认转场）、预览 |
| 处理 | 按顺序编排片段清单，生成顺序预览数据与导出配置 |
| 输出 | `videoAssembly`（片段清单 / 导出配置）、结构化文件与工程包导出 |
| 关键规则 | **VID-01/02/03**：唯一片段编排点，只产出片段清单 / 导出配置 / 顺序预览数据与结构化文件，**不生成 mp4 / webm 视频文件**，不做音画合成与音频合并，不提供视频下载；导出为结构化文件（JSON / CSV）与工程包，不含 API Key |

## F-012 AI 短剧导演（四段）

| 项 | 内容 |
| --- | --- |
| 输入 | 一句话创意、目标集数 / 单集时长、本地数据（场次 / 分镜 / 成品）、复核范围、目标视频模型 |
| 处理 | ① 规划：生成导演规划书（7 字段齐全）② 执行：拆 11 条模块任务并按真实数据重算状态 ③ 复核：15 项检查（7 基础 + R-01~R-08 规则库注入）④ 提示词架构：镜头时间轴 23 维度 → 目标模型成品提示词 + 6 类一致性约束 |
| 输出 | `directorPlans`、`directorTasks`、`directorReviews`、`reviewFindings`、`shotDeconstructions`、`promptArchitectResults`、`reverseAnalyses` |
| 关键规则 | 复核不通过只给结论与建议，**不阻断 F-001~F-011 任何操作与导出**；回写前显示将变更的条目ID 清单并需确认，只写建议字段与待办项，不覆盖剧本原文 / 分镜正文 / 锚点 / 锁定负面词；报告被复核对象变更后标记「已过期」；6 类一致性约束 = 人物变脸 / 服装脱落 / 肢体错位 / 背景闪烁 / 动作断裂 / 物理关系失真 |

## F-013 短剧规则库

| 项 | 内容 |
| --- | --- |
| 输入 | 阶段筛选（剧本 / 分镜 / 画面资产 / 视频 / 审阅）、类型筛选、关键词、固定 / 取消固定、模板与构图推荐 |
| 处理 | 读取内置只读规则与模板，双维筛选，按项目维护固定引用 |
| 输出 | `rulesLibrary.固定引用`（固定ID / 规则ID / 固定时间）；规则本体与模板、构图预设为包内只读数据 |
| 关键规则 | 内置规则 **18 条**（剧本 3 / 分镜 5 / 画面资产 4 / 视频 4 / 审阅 2）只读、不提供用户改写入口；模板 5 套（T-01~T-05），构图预设 24 个；固定操作幂等，重复固定不产生第二条引用；「是否固定到项目」由固定引用派生，不存第二份布尔 |

## 全局横切能力

| 能力 | 说明 |
| --- | --- |
| 统一响应四类 | ①真实执行并产生可见结果 ②禁用态且显示具体原因 ③空状态引导 ④Toast 明确反馈；未登记的可点击元素由兜底 Toast 提示，不静默失败 |
| 唯一点击委托 | 全应用仅一个 click 监听，所有可点击元素带 `data-btn-id` 并登记，缺登记即被 `auditButtons` 报出 |
| 密钥剥离 | API Key 只写本地密钥通道（`ai-drama:secrets:v1`），工程 JSON 与导出物结构上不含该键；导出前再做一次「无密钥」校验 |
| 演示数据标注 | 任务卡片角标、来源标识条、底部状态栏三处同源标注；强制演示数据开启时零外部请求 |
| 动效开关 | 关闭动效后全部动效归零，玻璃层直接不透明，功能与信息完整保留 |
| 数据存放 | 工程数据只存浏览器 localStorage（主槽 + 备份槽），不上传任何服务器 |
