## 3. CR-01 运行与交付约束（需求级，不替架构师选型）

### 3.1 约束表

| 编号 | 需求级约束 |
| --- | --- |
| CR01-01 | **零本地服务**：用户不在本机启动任何服务、进程、终端命令，不安装运行时、不执行构建命令；浏览器打开 Gitee Pages 在线地址即进入应用 |
| CR01-02 | **零后端**：仓库内为纯静态资源。Gitee Pages 仅做静态文件分发，不得依赖服务端渲染、接口转发、数据库、函数计算、环境变量注入、OAuth 回调、跨域代理等任何服务端能力 |
| CR01-03 | **在线访问**：桌面浏览器打开在线地址即可使用；免登录、无账号体系（V1 §2 继续有效） |
| CR01-04 | **工程数据仅存用户本地浏览器**：剧本文本、资产、图片、工程数据、模型配置仅存当前浏览器本地存储；不上传 Gitee、不上传任何第三方；仓库内不含任何用户工程数据 |
| CR01-05 | **无需付费服务、无需任何 API Key**：零配置即可靠内置演示数据走通 F-001~F-012 全流程（含导演规划书、执行指令清单、复核报告），演示数据路径零外部请求；真实模型配置仅为可选增强 |
| CR01-06 | **密钥不落盘不外泄**：K-01~K-05 继续有效；密钥不得写入仓库任何文件、提交物、Pages 可访问静态资源、README、示例、URL 与日志；导出自动剥离（K-02） |
| CR01-07 | **边界声明**：凡需服务端能力、需用户本机常驻进程、需本机编码/安装运行时的方案一律 Out of Scope；VID-03「不产出 mp4/webm、只做结构化编排」边界不变 |

### 3.2 本变更使 V1 / 上游失效的运行假设

1. V1 R-01「浏览器可直接打开」隐含的本机运行假设失效，改由在线地址承载。
1. V1 R-06 与 VID-04 中「浏览器可运行」语境改写为「在线静态页面内运行」；VID-04 的「本地编码能力」仅指页面内运行的能力，**不得**解释为用户本机进程，且 VID-03 本轮验收边界不变。
1. V1 A-08「工程保存采用本地持久化」限定为**浏览器端本地存储**，不含本地文件服务写入。
1. V1 §7.2 云端同步条目按 X-09 澄清：代码上云 ≠ 工程数据上云。
1. Phase 3 §1.4「`file://` 不可运行 → 必须起本地服务」的论证链整体作废，改由 Pages 提供的同源 HTTP 承载；该论证涉及的 ESM、相对路径、内联演示数据等技术结论是否保留由架构师在方案重做时重新论证，本 V2 不选型。

## 4. CR-02 新增 F-012 AI 短剧导演（全局统筹 Agent）

### 4.1 定位与三段状态流转

- **定位**：不替代用户操作、不是单一诊断面板、不自动改写工程数据（除用户主动触发「一键回写修正」）。职责为给出「下一步该做什么 + 参数建议 + 状态追踪 + 复核结论」。
- **贯穿性**：横切贯穿 V1 §3 步骤 1~~12 的 12 步主链路；有导航级独立入口；F-001~~F-011 任一模块可跳转至导演模块，导演任务清单可一键跳回目标模块。

| 流转 | 可判定进入条件 | 结果 |
| --- | --- | --- |
| 无 → Plan | 用户进入导演独立入口 | 产出 DirectorPlan；7 项字段全非空方可流转 |
| Plan → Execute | DirectorPlan 存在且 7 项必填字段非空 | 产出 11 条 DirectorTask + 全局进度 |
| Execute → Review | 剧本 / 场次 / 分镜脚本 / 分镜成品**任一**存在 | 产出 DirectorReview；无对象时入口按 CR-05 第③类显示空状态引导，不产出「全通过」报告 |
| Review → 回流 | 用户执行「一键回写修正」或被复核对象发生编辑 | 相关 DirectorTask 状态回到「进行中 / 未开始」，旧报告标记「已过期」，不自动重跑复核 |
| 任一段 | 三段可重复进入、互不清空；产物变更后已有报告一律标记「已过期」 | 过期结论不得作为当前结论展示 |

### 4.2 规划 Plan

- **输入**：一句话创意文本 / 已导入剧本原文（二选一或并存）+ 用户设定的集数目标（整数）+ 每集时长目标（分钟，数值）；可选题材与视觉基调倾向。
- **处理**：需文本模型分析时**必须经 V1 §6 统一模型适配层**（用途：agnes-ai 文本），禁止 F-012 自建调用通道；未配置 / 未启用 / 失败按 D-01~D-06 降级演示数据，规划书须标注「演示数据」来源。
- **输出**：《导演规划书》DirectorPlan，**7 项可判定字段**：建议集数（整数）、每集场次数（整数）、角色表（角色名列表 + 人数）、视觉基调（非空文本）、表演密度目标（每场次动作描述条数下限）、旁白占比上限（百分数）、台词覆盖率下限（百分数）；另含规划依据、生成时间、数据来源标记。
- **关键规则**：① 7 项缺一不可，空输入不生成并显示必填提示（E-01 口径）；② 建议集数与每集场次数须与用户设定目标数值自洽，用户未填时采用内置默认目标并标注 `[假设]`；③ 三项阈值**直接引用 CR-03 统一诊断口径配置**，不得另设第二份（G-1）；④ 规划书可编辑，重新拆解执行清单前须一次显式确认，不静默覆盖；⑤ 随工程保存/恢复/导出（扩展 S-03）。

### 4.3 执行 Execute

- **输入**：DirectorPlan + 当前工程真实数据（V1 §5 各类对象）。
- **处理**：把规划拆解为面向 F-001~F-011 共 11 个下游模块的任务指令清单，每条映射唯一目标模块；拆解逻辑单一实现。
- **输出**：DirectorTask 列表 + 全局进度（已完成数 / 总数 / 受阻数）。每条必含 5 要素：**目标模块 ID、建议参数、前置条件、当前状态、一键跳转入口**。
- **关键规则**： **状态来自真实工程数据，不得写死假状态**。四值枚举：`未开始 · 进行中 · 已完成 · 受阻`；每条须记录「状态判定依据」，明确由哪个真实字段或条目数判定（例：F-002「已完成」= 场次条目数 > 0 且可列出全部场次ID；「受阻」= 前置条件未满足并列出缺失对象ID；「未开始」= 无相关产物；「进行中」= 存在进行中 GenTask 或已产出部分条目）。逐模块映射表由设计与方案冻结，但必须逐条可追溯。 状态随工程数据变化刷新；**不允许手动伪造「已完成」**；真实对象被删除后状态回落并列出缺失 ID。 受阻项须列出具体缺失条目 ID 与原因，禁止「请稍后」类措辞。 「一键跳转入口」点击须跳到目标模块并带入建议参数，落入 CR-05 四类响应之一。 建议参数为结构化键值（如建议集数 / 建议场次数 / 目标镜头数 / 目标旁白占比），须可直接被目标模块读取。

### 4.4 复核 Review

- **输入**：剧本原文、F-002 场次、F-005 分镜脚本、F-010 分镜成品、V1 §5 锚点 / 负面词 / 关键帧 / GenTask 数据；CR-03 统一诊断结果（直接引用，不重算）。
- **处理**：执行 7 项一致性检查；需文本模型时走 V1 §6 统一适配层，降级按 D-01~D-06。
- **输出**：《导演复核报告》DirectorReview：总判定（**通过 / 不通过**二值）、检查项结果表（检查项 / 实测值 / 阈值 / 结论）、ReviewFinding 列表、复核范围对象ID列表、数据来源标记、是否过期、生成时间。

| # | 检查项 | 可判定口径 |
| --- | --- | --- |
| 1 | 锚点携带完整性 | 涉及角色的分镜成品与生成任务，最终提示词快照含锁定锚点标识比例 = 100%（ANC-02 / NEG-06）；缺失列具体分镜ID / 任务ID |
| 2 | 全局锁定负面词出现率 | 生成任务最终负面词含全部锁定词比例 = 100%（NEG-06）；缺失列任务ID + 缺失词文本 |
| 3 | 旁白占比 | 按 CR-03 公式计算，≤ 上限 |
| 4 | 台词覆盖率 | 按 CR-03 公式计算，≥ 下限 |
| 5 | 表演 / 动作描述密度 | 每场次动作描述条数 ≥ 下限且字数 ≥ 下限；不足列场次ID + 实测值 + 下限值 |
| 6 | 场次可执行性 | 每场次 ≥1 条分镜、每条六项字段非空、镜号在场次内唯一升序（V1 F-005）；不满足列场次ID / 分镜ID |
| 7 | 缺失帧与缺失资产 | 关键帧缺失条数、被引用但无锚点资产数、悬空引用 ID 数（E-15/E-16），逐条列 ID |

## 5. CR-03「少旁白、多表演和台词」可判定诊断规则

### 5.1 统一口径（唯一实现，禁止各模块各写一套 · G-1）

- **切分**：以中文句号 / 问号 / 叹号 / 分号 / 换行为句子边界，按「集 > 场次」逐场次扫描；一句话只归一类，不重复计数。
- **判定优先级（命中即停）**：① **台词**——含「角色名 + 冒号/引号」前缀，或位于 F-005「对白」字段；② **动作/表演描述**——含显式动作动词、括号/方括号包裹的舞台指示，或位于 F-005「画面描述」字段；③ **旁白/解说句**——不属前两类、以第三人称全知视角叙述背景、时间流逝、人物内心、剧情概括、场景交代的句子；典型标记词「旁白 / 画外音 / 解说 / 多年以后 / 与此同时 / 原来 / 从此」或无角色归属的环境、心理、背景陈述。
- 演示数据按同一口径切分与计数，不适用特殊规则。

### 5.2 公式与阈值（`[假设 A-15]`，用户可一次性调整，只改配置不改实现）

| 指标 | 公式 | 建议阈值 |
| --- | --- | --- |
| 旁白占比 | 旁白句数 ÷ 句子总数 × 100%；分母 = 台词句 + 动作描述句 + 旁白句 | **上限 15%**；不通过线 > 30% |
| 台词覆盖率 | 有台词场次（台词句数 ≥1）÷ 总场次（F-002 拆分条目数）× 100% | **下限 80%**；不通过线 \< 60% |
| 表演/动作描述密度 | 每场次动作描述**条数 ≥ 2** 且**总字数 ≥ 20 字**，两项同时满足 | 未达标场次占比 > 30% 为不通过线 |

- 文本为空或总场次为 0 时不计算比例，直接判「不通过」并给出原因。
- 三个阈值存于**单一诊断口径配置**，ScriptDiagnosis 记录「诊断口径版本」；DirectorPlan 的三项目标值直接引用该配置，禁止硬编码第二份。

### 5.3 诊断等级（三值可判定）

| 等级 | 判定条件 |
| --- | --- |
| 通过 | 旁白占比 ≤15% 且 台词覆盖率 ≥80% 且 全部场次密度达标 |
| 需改写 | 任一项超阈值但未达不通过线（占比 15%~30% / 覆盖率 60%~80% / 未达标场次 ≤30%） |
| 不通过 | 占比 >30% 或 覆盖率 \<60% 或 未达标场次 >30% 或 文本为空 / 总场次为 0 |

F-012 复核引用本等级：「不通过」产生阻塞级 ReviewFinding，「需改写」产生提示级；二者均**不阻断**下游操作（A-17）。

### 5.4 改写建议格式

每条建议必须含 4 字段：**对象ID（场次ID/分镜ID） | 原句（逐字引用旁白句） | 建议替换（改写为可直接使用的台词句或动作描述句，并标注类型） | 理由**（引用触发的判定规则与实测值，如「该句为全知背景陈述，计入旁白；当前旁白占比 22% > 15%」）。一条原句对应一条建议替换；不得改变人物、时间、地点、因果等剧情事实；不自动写回原文（回写边界见 §4.4）。

### 5.5 作用范围

| 模块 | 调用方式 |
| --- | --- |
| F-001 生成/导入剧本 | 产出后调用统一诊断，显示摘要与等级；导入剧本**不做静默改写**（V1 F-001 继续有效），只出结论 |
| F-002 拆分 | 按场次输出台词覆盖率与逐场次密度 |
| F-005 分镜脚本 | 对「画面描述」「对白」字段按同一口径诊断，旁白占比以场次汇总 |
| F-012 复核 | 直接引用同一 ScriptDiagnosis 结果，不重算、不另写口径 |

统一实现：诊断逻辑收敛为单一公共模块，四者只传入对象 ID 与文本、返回 ScriptDiagnosis；任一模块不得自行实现切分与阈值判断。内置演示数据剧本须满足「通过」等级，保证零密钥体验不出现自相矛盾的诊断结论。

## 7. CR-05 全量按钮可响应性（硬性验收）

### 7.1 四类合法响应（任何按钮必须落入其一，无第五类）

| 类 | 定义 | 可判定表现 |
| --- | --- | --- |
| ① 真实执行并产生可见结果 | 点击后出现与按钮语义一致的可观测变化（数据变更 / 跳转 / 弹层 / 列表更新 / 文件下载） | 变化可见且可复现 |
| ② 禁用态且显示禁用原因 | 置灰不可点或点击无副作用，并在按钮上/邻近/提示中显示**具体可操作原因**（如「请先生成剧本」「前置条件未满足：缺场次」） | 原因含具体缺失项，非「不可用」泛化文案 |
| ③ 空状态引导 | 无数据时说明缺什么 + 给出下一步可点入口，入口再落入① | 引导入口可达目标页面 |
| ④ Toast / 明确反馈 | 无需产生数据变化的操作（复制、已最新、无变更、非法指令）须在 1 秒内给出明确文字反馈，说明发生了什么或为何未执行 | 反馈文案可读、非空 |

### 7.2 禁止情形（出现即不通过）

静默点击（无任何可见变化、无文字反馈、无按压/加载态）；点击后控制台新增 error（含未捕获异常、404、Promise rejection）；假响应（仅播放动效无语义结果）；「敬请期待 / 即将上线」占位入口（覆盖 F-012 全部入口，V1 S-01 重申）；异步操作无进行中态（V1 F-006 状态可见）。

### 7.3 交付物与核验责任

- **「按钮-响应」清单为 Phase 2 设计交付物**，由产品设计师产出并随契约冻结：逐页列出 按钮ID / 所在页面 / 语义 / 落入类别 / 响应内容 / 禁用原因文案 / 空状态文案 / Toast 文案 / 关联 F-ID；覆盖 F-001~F-012 全部页面的全部可点击元素（含图标按钮、链接、卡片跳转、一键跳转入口、一键回写、导出、确认弹窗按钮），不得遗漏。开发期间新增按钮须先更新清单。
- **qa-verifier 逐页核验并出具《按钮可响应性核验报告》**：逐按钮记录实测响应类别与通过结论，附控制台日志结论。

### 7.4 可判定断言

- **A**：给定清单，当逐页逐按钮点击，则每个按钮实测响应落入四类之一且与清单类别一致，静默点击数为 0。
- **B**：给定全量点检，当收集控制台输出，则新增 error 数为 0。
- **C**：给定任一禁用态按钮，当查看说明，则含具体可操作原因，泛化文案数为 0。
