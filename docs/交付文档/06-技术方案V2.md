## 11. 运行架构重新定案（Gitee Pages 在线静态站点）

**唯一结论**：仓库内纯静态资源，浏览器打开 `https://<user>.gitee.io/<repo>/` 即进入应用；零本地服务、零后端、零构建、零密钥、免登录。以下逐条给唯一解，不两头下注。
**(a) 子路径／基础路径**：URL 带仓库名子路径 → **所有资源引用一律相对路径，禁止 `/` 开头绝对路径**。唯一方案＝**全部相对引用，不采用 `<base>`**。理由：`<base>` 会整体改写页面内相对 URL 基准，波及 hash 路由、锚点、内联 SVG `url(#…)`、form action；子路径随用户名/仓库名/自定义域名变化，写死 base 必失效；`./`、`../` 配合 ESM import 图天然适配任意挂载深度、零配置。具体路径待第二块，本块只冻结「相对 + 带 `.js` 后缀」形式。
**(b) 刷新 404／路由**：Pages 无 history fallback，`pushState` 的 `/p005` 刷新必 404。唯一方案＝**`location.hash` 路由**（hash 不发送服务器、零服务端配置）。

  ```
  #/<view>[/<stage>][?<params>]
  view   := p001…p011 | director     （12 步按 V1 §1.5 对照表映射；步骤 2 的 M-001 为叠加态 ?m=1）
  stage  := plan | execute | review  （F-012 横切层三段，不占步骤序号、不进上一步/下一步链）
  params := m=1 | from=director&<建议键值>（UI 态，不落工程；不可达按 E-27 落④）
  ```

恢复：`hashchange` 与启动时统一解析 `location.hash` → `setView()` 仅替换主工作区 DOM 子树；按 `stage` 恢复 C-14 活动区；滚动位置读 UI 键。**不重建 Project 引用**：浏览器整页刷新（F5）才 `main.js → loadProject()` 从 localStorage **恢复一次**（非 `createEmptyProject()` 空白重建）再按 hash 复位视图；应用内任何视图切换/hash 变化只 `setView`，**不 loadProject、不新建引用**。一键跳转参数进 hash 查询串（不落工程），目标页仅显示「来自导演建议参数」标识条、可清除、不自动写入。
**(c) ES module**：`file://` CORS 论证链作废；同源 HTTP(S) 原生 ESM 正常。import 必须**相对且写全 `.js` 后缀**，禁 import maps/裸模块名；演示数据/文案/枚举一律 `.js` 导出常量，不 `fetch` 本地 `.json`。**加载失败可见降级**：入口放非 module 兜底脚本，捕获阶段监听 `error`/`unhandledrejection`，模块图加载或执行失败时根容器渲染常驻可读块「应用模块加载失败：＜原因＞，请刷新页面重试；工程数据未改动」并出④明确反馈，**禁止静默白屏、禁止只写 console.error**（CR-05④）。
**(d) 模型请求跨域／可替换点**：浏览器直连自定义 Base URL 需对方返回 CORS 头；未返回则拦截，按 D-01 降级并给可读错误、不阻断。agnes-ai 真实文档未提供（Q-05）时，沿用 V1 §6.2 **可配置 OpenAI 兼容风格 + 单一可替换适配函数** `registerAdapter(sourceType, adapterFn)`（覆盖 `buildRequest`/`parseResponse`）。**文档到位后只改 `core/model-adapter.js` 内 `DEFAULT_ADAPTERS` 注册表与解析函数**；`gen-task.js`、全部页面、`director.js` 等调用方**零改动**。演示数据路径零外部请求；**不引入服务端代理/函数计算/环境变量注入**。
**(e) localStorage**：Pages 免费版 `https://<user>.gitee.io/<repo>/` —— 同一用户名下多仓库**共享同一 origin**，localStorage 按 origin 而非路径隔离 → V1 四键的 `ai-drama:` 前缀是唯一命名空间（键名不改名），保证不同站点不串数据。工程数据仅存当前浏览器，Gitee 只托管代码与文档（X-09）。E-18 容量超限双槽 + `QuotaExceededError` 常驻 Toast、E-17 损坏不覆盖原始串 + C-04 恢复/新建，按 V1 §4.4 原样。导出/导入契约：`io.exportFile()`（stripSecrets→序列化→validateNoKey→Blob+`createObjectURL`+`<a download>`）、`importProject()`（FileReader→JSON.parse→migrate→validateProject）→ `hydrate()` **就地覆盖唯一引用、不新建对象、不 reload**。密钥剥离三落点不变：`saveProject()` 抽出到 SECRETS\_KEY（主/备槽永不含密钥）、`model-adapter.js` 请求时按配置ID 注入 `Authorization`、`io.exportFile()` 双保险；仓库提交物/Pages 静态资源/README/URL/日志一律不含密钥。
**(f) 零构建／零外链／动效开关**：不引入打包器、框架、CDN、外链字体/脚本/图标；图片一律内联 SVG dataURL。**视觉 token 落地**：设计 V2 §12 全部色板/玻璃/字号/五类动效时长/实底角标写入**单一 CSS 变量文件**（`:root{--bg-base…;--dur-hover:120ms;…}`），不重新设计视觉、不每页一份。**关闭动效**：根元素切换**单一 class `no-motion`**，一处 CSS 生效（全部 `transition/animation-duration:0`、玻璃层直接 `opacity:1`、光晕静止取透明度下限 6%、hover 仅即时描边/文字色），功能与信息完整不变（V-03）。真值＝Project 根 `关闭动效`（随工程保存/恢复 + UI 键），顶部 #10 与 P-012 B1 **读写同一字段、双向同步、不做两份实现**。
**(g) 取舍论证（≥5 条）**

| # | 理由 |
| --- | --- |
| 1 | **零本地服务**：打开 URL 即用，不启动进程/命令/装运行时（CR01-01）；本地 http.server 与轻量后端都要本机常驻进程 |
| 2 | **交付即一个地址**：免登录、免安装、免 zip、跨平台、git push 即发布；后两者交付为「目录+脚本+运行时」，S-02/CR07-01 难客观判定 |

| 4 | **零后端零运维零新增攻击面**：不引入第二套语言/HTTP 契约/前后端联调/进程单点/后端日志泄漏面（V1 §1.2③④⑤ 加强） |

  ```js
  // 伪代码：唯一诊断实现，四模块共用
  function diagnose(project, 对象类型, 对象ID, 文本) {
    const cfg = DIAGNOSIS_CONFIG, 总场次 = project.scenes.length;  // 总场次 = F-002 拆分条目数
    if (!文本?.trim() || 总场次 === 0) return make('不通过');  // §5.2：文本空/总场次 0 直接判不通过，不计算比例
    const 句 = splitSentences(文本), 类 = 句.map(s => classify(s, ctx));  // 一句话只归一类
    const 旁白句数 = 类.filter(c => c === '旁白/解说句').length;
    const 句子总数 = 类.length;                        // 分母 = 三类句之和
    const 旁白占比 = 旁白句数 / 句子总数 * 100;
    const 台词覆盖率 = 有台词场次(project, 文本) / 总场次 * 100;
    const 密度 = 逐场次(动作描述条数 >= cfg.每场次动作描述条数下限 && 动作描述字数 >= cfg.每场次动作描述字数下限);
    const 未达标占比 = 未达标场次 / 总场次 * 100;
    // 判定优先级：先判不通过线，再判通过线，否则需改写（§5.3 三值，无模糊中间态）
    const 诊断等级 = (旁白占比 > cfg.旁白占比不通过线 || 台词覆盖率 < cfg.台词覆盖率不通过线
                   || 未达标占比 > cfg.未达标场次占比不通过线) ? '不通过'
                   : (旁白占比 > cfg.旁白占比上限 || 台词覆盖率 < cfg.台词覆盖率下限
                   || 未达标占比 > 0) ? '需改写' : '通过';
    return { ...逐字段, 诊断等级, 诊断口径版本: cfg.VERSION, 生成时间: now() };
  }
  ```
