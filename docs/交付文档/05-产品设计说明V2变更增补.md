| 项 | 规格 |
| --- | --- |
| 模糊半径 | 面板级 `blur(18px)`；卡片级 `blur(12px)`；悬浮/模态 `blur(24px)`；配 `saturate(120%)`；**不模糊文字层** |

| 内阴影 / 高光 | `inset 0 1px 0 rgba(255,255,255,.06)`；卡片顶部渐白高光 ≤8%，不加第二道彩色描边 |
| 圆角分级 | 4px 标签/输入框/角标；8px 按钮/节点卡；12px 玻璃面板/SectionCard/任务卡；16px 模态/C-14 三区/抽屉 |

| 层级叠加顺序 | **z0 背景光晕 → z1 玻璃层 → z2 内容（文字/表格/按钮）→ z3 悬浮层**（Toast/Modal/下拉/导演浮层），逐层只升不降 |

### 12.4 动效规范

**允许的克制微动效（仅此 5 项）**

| 动效 | 时长 | 缓动 | 表现 |
| --- | --- | --- | --- |
| hover 提亮 | 120ms | `ease-out` | 玻璃层/按钮亮度 +6%，描边转 `--accent` |
| 玻璃层入场淡入 | 160ms | `ease-out` | `opacity 0→1`，仅首次挂载，不重复播放 |
| 状态切换过渡 | 150ms | `ease-in-out` | StatusTag 背景/文字色过渡，不位移 |
| 按钮按压反馈 | 80ms / 回弹 100ms | `ease-in` | `scale(.98)` + 亮度 −4% |
| 抽屉 / 模态入场 | 180ms | `ease-out` | `opacity + translateY(8px)→0` |

**禁止的动效**：遮挡内容（光晕/粒子/渐显遮罩覆盖文字、表格、按钮）；循环闪烁、呼吸、跑马灯、光晕持续动画；阻塞点击（动效期间拦截 `pointer-events`、加载遮罩盖住可点区）；位移导致误点（hover 位移 \>2px、按钮自动移动、列表重排动画）；假响应（仅播放动效无语义结果，CR-05 §7.2）。

**全局「关闭动效」开关（V-03）**

| 项 | 规格 |
| --- | --- |
| 位置 | 顶部工程栏新增 **#10**，紧邻 #9「当前生效来源」右侧；P-012 B1 提供同源开关，**双向同步、不做两份实现** |
| 可达性 | 一次点击即切换，任何页面常驻可见，不藏于设置/抽屉 |
| 关闭后等价静态表现 | 全部 `transition/animation duration=0`；玻璃层直接以最终 `opacity=1` 呈现（无淡入）；hover 仅保留描边/文字色**即时**变化；状态切换瞬时；按压仅保留 1px 内阴影即时反馈；光晕保留但静止、透明度取下限 6%；**功能与信息完整不变**（V-02） |
| 持久化 | 状态写入本地配置随工程保存/恢复，不上传 |
