## 1. 项目目标与用户价值

- **一句话定位**：面向个人 AI 短剧创作者的一站式浏览器工作台，把「一句创意 → 剧本 → 资产/锚点 → 分镜脚本 → 图片/关键帧 → 画布 → 分镜表 → 片段清单」串成一条连续链路。
- **目标用户**：非工程师的 AI 短剧爱好创作者，个人独立创作，无团队协作、无运维能力。
- **核心价值**：消除在多个工具间反复复制粘贴；全部中间产物在同一工程内可编辑、可追溯、可保存恢复；生成时的一致性约束（角色锚点、负面词）由系统强制携带，不依赖创作者记忆。
- **成功标准（可量化）**：

| 编号 | 成功标准 |
| --- | --- |
| S-01 | 11/11 功能模块均可交互走通，无静态占位页、无「敬请期待」入口 |
| S-02 | 零密钥体验：不配置任何 API Key，可在单一浏览器应用内从空白工程连续执行到导出片段清单，全程不依赖外部工具与付费服务 |
| S-03 | 工程保存 → 重新打开，第 5 章 11 类数据对象条目数与保存前差异为 0 |
| S-04 | 抽查任一生成任务的最终提示词快照，锁定负面词与锁定角色锚点的携带率为 100% |
| S-05 | 画布三种自动创建指令执行后，节点数与所选数据源条目数一致率为 100% |
| S-06 | 视频整合产出结构化片段清单与导出配置，且不产出 mp4/webm 等真实视频编码文件（边界声明） |

## 2. 角色与权限

| 角色 | 说明 | 可做的事 | 不能做的事 |
| --- | --- | --- | --- |
| 个人创作者（唯一角色） | 非工程师，独立创作，本地使用，工程数据归属本人 | F-001~F-011 全部功能的增/删/改/查；模型配置；锚点与负面词的锁定/解锁；工程保存/恢复/导出/导入；画布节点编辑 | 无功能层面的限制；不存在「访问他人数据」这一行为，因系统内不存在他人数据 |

**明确结论**：
1. **不需要登录、不需要账号体系**；应用打开即可使用。
1. **不需要多用户、不需要权限矩阵、不需要角色分配**。
1. **不需要服务端用户体系**；R-04 已约束数据本地归属。

> 该结论为已决项，不作为待确认项；后续设计不得引入注册/登录/邀请等入口。

## 3. 核心业务流程（端到端主链路）

> 流程按**实际数据依赖**排列，与功能编号顺序不完全一致：提示词组与角色锚点须在首次生成类任务前完成配置，且可在任意时刻调整，调整仅影响此后新发起的任务。

1. **创意/剧本输入** → 创作者输入一句话创意由文本模型生成剧本，或粘贴/上传已有剧本 → 得到剧本文本并建成工程 `[F-001]`
1. **模型准备（可选）** → 配置 agnes-ai 文本 / agnes-ai 媒体 / 自定义模型；未配置则全程使用内置演示数据 `[第 6 章，贯穿]`
1. **拆分剧本** → 按集 / 按场次拆分为结构化条目，人工校正拆分结果 `[F-002]`
1. **分解提取资产** → 从剧本文本提取人物、场景、道具并结构化列出，人工增删改 `[F-003]`
1. **建立人物锚点** → 为角色填写外貌/服装/特征、锚点标识、参考图，并置为「锁定」 `[F-004]`
1. **配置提示词组** → 填写全局正向提示词、全局负面提示词，将负面提示词置为「锁定」 `[F-008]`
1. **生成分镜脚本** → 把每个场次转为分镜条目（镜号、景别、运镜、画面描述、对白、时长） `[F-005]`
1. **图片生成** → 为资产/场景生成图片，任务自动携带角色锚点与锁定负面词 `[F-006，受 F-004/F-008 约束]`
1. **关键帧生成** → 为每个分镜生成首帧/尾帧，任务自动携带角色锚点与锁定负面词 `[F-007，受 F-004/F-008 约束]`
1. **画布生成** → 在画布对话框提交「按场次/按分镜/按资产生成」，自动创建并布局节点 `[F-009]`
1. **分镜生成** → 组装「分镜脚本 + 关键帧 + 生效提示词」为分镜成品/分镜表，可导出 `[F-010]`
1. **视频整合** → 按镜号顺序生成片段清单与导出配置，提供应用内顺序预览与结构化文件导出 `[F-011]`
1. **工程保存 / 恢复** → 任意节点可保存，重新打开后从保存点继续 `[R-03，贯穿]`
**主链路验收口径**：步骤 1 → 12 在零密钥条件下可一次连续执行完毕，中间不产生需要人工到外部工具转录的环节。

## 4. 功能模块需求清单（11 项）

> **优先级声明**：F-001 ~ F-011 优先级均为 **P0，本期必交付、不可裁剪**（依据用户已确认决策 1：11 个模块都要能交互走通，不是静态原型稿）。逐条不再重复标注优先级。

### F-001 一句话生成剧本 + 导入剧本

- **输入**：一句话创意文本；或粘贴的剧本文本；或上传的剧本文件；生成/导入方式二选一。
- **处理**：生成方式调用文本模型（未配置则用演示数据）产出剧本文本；导入方式读取文本并按原样写入工程，不做静默改写。两条入口共用同一个「剧本项目」对象。
- **输出**：剧本文本 + 剧本来源标记（生成 / 导入）+ 新建工程。
- **关键规则**： 空输入不发起生成、不创建空工程，显示必填提示。 导入文本与粘贴/文件内容逐字一致；不做静默格式清洗。 导入文件仅支持纯文本类 `[假设 A-11]`；不支持的格式明确报错，不写入脏数据。 重新生成或重新导入前，若工程已有剧本内容，须一次显式确认后再覆盖。

### F-002 拆分剧本

- **输入**：剧本文本；拆分方式（按集 / 按场次）。
- **处理**：按所选方式产出结构化条目并保留原文片段；拆分结果全部可编辑（增、删、改、调整序号）。
- **输出**：集列表（集号、标题、所属场次）与场次列表（场次序号、地点、时间、出场人物、正文）。
- **关键规则**： 「场景」与「场次」在本说明书中合并为同一层级「场次（Scene）」，数据层级固定为 **集 > 场次 > 分镜** `[假设 A-02]`。 拆分后场次序号连续、无重复；产出条目数可数、可与剧本标记数比对。 编辑任一条目并保存后，重新读取必须为编辑后的值。 拆分结果被后续模块引用；删除场次时，其下属分镜与关联数据的处理见第 8 章 E-16。

### F-003 分解提取资产

- **输入**：剧本文本或已拆分场次文本。
- **处理**：由文本模型（或演示数据）提取人物、场景、道具三类资产，结构化列出；结果全部可编辑。
- **输出**：资产列表，每条含 资产ID、类型（人物/场景/道具）、名称、来源文本片段、备注。
- **关键规则**： 每条资产必须带「来源文本片段」，可回溯到剧本原文。 支持人工新增剧本中未提取到的资产；新增资产同样可参与后续锚点与生成。 资产类型仅三类，不扩展至音效/音乐/特效等（Out of Scope）。

### F-004 人物锚点锁定

- **输入**：资产中类型为「人物」的条目；外貌/服装/特征描述文本；锚点标识；参考图（可选）；锁定/解锁操作。
- **处理**：为角色建立一致性锚点；锁定后，在后续生成任务组装提示词时强制注入锚点内容。
- **输出**：资产锚点对象（含锁定状态）；生成任务的「最终提示词快照」中可见锚点内容。
- **关键规则**： **【强制规则 · ANC-01｜粒度与内容】** 锚点按**单个角色**独立建立与锁定；字段固定为 外貌描述、服装描述、特征描述、锚点标识、参考图（可选）、锁定状态。 **【强制规则 · ANC-02｜生效范围】** 角色锚点锁定后，凡生成任务的画面涉及该角色（即分镜或资产关联了该角色），F-006 图片生成、F-007 关键帧生成、F-010 分镜生成**均自动携带**该角色的锚点描述、锚点标识与参考图，无需人工填写。 **【强制规则 · ANC-03｜优先级】** 锚点字段 **>** 单条正向提示词中的同类描述。单条正向词中与锚点冲突的外貌/服装/特征描述不生效，并在任务快照中标记为「被锚点覆盖」；单条正向词可追加非冲突描述（动作、光线、构图、景别等）。最终正向提示词 = 全局正向词 + 角色锚点 + 单条正向词（冲突部分被锚点覆盖）。 **【强制规则 · ANC-04｜解锁与缺失】** 解锁后新任务不再携带该角色锚点；角色无锚点或锚点未锁定时，任务可继续生成，但显示「角色 X 无有效锚点，不保证一致性」并列出缺失锚点清单。 **【强制规则 · ANC-05｜不回溯】** 锁定、解锁、编辑锚点只影响**此后新发起**的生成任务，已生成的图片、关键帧、分镜成品不回溯修改。 **【强制规则 · ANC-06｜与负面词并行】** 锚点属正向侧约束，与 F-008 负面词锁定并行生效、互不覆盖；任一侧规则被违反均单独可判定。

### F-005 分镜脚本

- **输入**：单个或批量场次；生成指令。
- **处理**：由文本模型（或演示数据）把场次转为分镜条目；结果全部可编辑。
- **输出**：分镜条目列表，每条含 **镜号、景别、运镜、画面描述、对白、时长** 六项必填字段，并关联所属场次ID与出场资产ID列表。
- **关键规则**： 六项字段缺一不可；演示数据同样产出六项完整字段。 镜号在场次内唯一且升序；分镜顺序即为后续画布布局、分镜表、片段清单的默认顺序。 分镜脚本为**结构化文本条目**，与 F-010「分镜成品」是不同对象，不得合并实现（语义区分见附录 A）。

### F-006 图片生成

- **输入**：资产或场景条目；关联角色锚点；全局与单条提示词；媒体模型配置。
- **处理**：调用媒体模型（未配置/不可用则演示数据）生成图片；每个请求创建一个生成任务对象。
- **输出**：图片结果（预览引用）+ 生成任务（状态、耗时、来源标识、最终提示词快照）。
- **关键规则**： 生成状态可见：待处理 / 进行中 / 成功 / 失败 / 已降级（演示数据）。 结果提供缩略预览，并标明所属资产/场景ID。 任务自动携带 F-004 锚点与 F-008 锁定负面词；不得提供「跳过锚点/跳过锁定词」的单条开关。 同一对象在任务进行中重复点击不产生第二个并行任务（去重置灰）。

### F-007 关键帧生成

- **输入**：分镜条目；分镜关联的角色锚点；关键帧与提示词。
- **处理**：为每个分镜按帧类型生成关键帧图片；每个请求创建一个生成任务。
- **输出**：关键帧对象（帧ID、分镜ID、帧类型、图片引用、生成任务ID、状态）。
- **关键规则**： 默认帧类型为**首帧 + 尾帧**共 2 张 `[假设 A-04]`；帧类型可配置，但每个分镜至少产出 1 张。 关键帧必须关联到唯一分镜ID，可被 F-010、F-011 按镜号顺序引用。 任务的最终提示词快照中，锁定角色锚点与锁定全局负面词携带率 100%（与 F-006 共用同一套组装逻辑，不重复实现）。 生成失败/降级不阻断分镜表与片段清单的后续组装（缺失帧以明确占位标记呈现，不伪造图片）。

### F-008 提示词（正向编辑 + 负面词全局锁定）

- **输入**：全局正向提示词文本；全局负面提示词文本；锁定/解锁操作；各生成任务的单条提示词。
- **处理**：维护唯一一份提示词组对象；在生成任务组装时按锁定状态合成最终提示词。
- **输出**：提示词组对象；每个生成任务的「最终提示词快照」（正向、负面、来源标记）。
- **关键规则**： **【强制规则 · NEG-01｜生效范围】** 负面词置为「锁定」后，对**此后新发起的全部生成任务**（F-006、F-007、F-010）生效；对锁定前已完成的产物不回溯。 **【强制规则 · NEG-02｜自动附加】** 锁定状态下，每个生成任务的最终负面提示词 = **全局锁定负面词集合 ∪ 该任务单条负面词集合**（去重），全局锁定词必定出现。 **【强制规则 · NEG-03｜不可覆盖】** 单条任务不得删除、置空、覆盖或注释掉任何全局锁定词；此类操作被拒绝并提示「该负面词已被全局锁定，不可移除」。单条任务**仅可追加**自身负面词。 **【强制规则 · NEG-04｜优先级与冲突】** 冲突优先级：**全局锁定负面词 > 单条负面词 > 无**。当单条任务声明「移除/排除」某锁定词时，以全局锁定词为准，锁定词仍保留在最终负面提示词中。 **【强制规则 · NEG-05｜解锁】** 执行「解锁」需一次显式确认；解锁后新任务不再自动附加原锁定词；解锁不修改历史产物，也不删除提示词组中已保存的词文本。 **【强制规则 · NEG-06｜可判定】** 任一生成任务可查看「最终提示词快照」；抽查时，锁定词在快照中的出现率必须为 100%，且不存在「单条删除后锁定词消失」的情况。 正向提示词支持全局编辑与单条编辑；正向侧不做全局锁定（锁定能力仅约束负面词），正向冲突按 ANC-03 处理。

### F-009 画布生成（画布内对话框 · 自动创建）

- **输入**：画布对话框中的文本指令；当前工程的数据源（场次 / 分镜 / 资产）；作用范围（当前集 / 全集，默认当前集 `[假设 A-06]`）。
- **处理**：解析指令 → 选取数据源 → 按规则创建并布局节点 → 写入画布。节点支持在画布内编辑标题/摘要与拖动位置。
- **输出**：画布节点列表（节点ID、类型、标题、关联数据ID、布局坐标、摘要）。
- **关键规则**： **【强制规则 · CNV-01｜触发条件】** 用户在画布对话框提交且指令**精确匹配**以下三种之一时触发自动创建：`按场次生成`、`按分镜生成`、`按资产生成`。除此之外不触发。 **【强制规则 · CNV-02｜一一对应】** 执行后 **画布节点数 == 所选数据源条目数**；每个节点通过「关联数据ID」与唯一一条数据源记录绑定，节点标题取该记录的场次名 / 镜号 / 资产名。 **【强制规则 · CNV-03｜布局规则】** 按场次 → 按场次序号升序；按分镜 → 按镜号升序；按资产 → 先按资产类别（人物/场景/道具）分组、组内按创建序。统一采用单向顺序排列，不引入自动布局算法。 **【强制规则 · CNV-04｜重复执行】** 同一指令重复提交时按当前数据源**全量重建**：执行后节点数仍等于数据源条目数，不叠加重复节点。执行前若画布非空，先给出一次确认提示；确认后清空画布再重建。 **【强制规则 · CNV-05｜空状态】** 数据源条目数为 0 或工程无剧本时，**不创建任何节点（节点数 == 0）**，对话框显示「数据源为空：缺少场次 / 分镜 / 资产」及缺失原因，不生成占位空节点。 **【强制规则 · CNV-06｜非法指令】** 指令不匹配 CNV-01 三种之一时，节点数不变，对话框列出支持的三种指令格式。 **【强制规则 · CNV-07｜节点可编辑】** 节点在画布内的编辑与拖动不改变其「关联数据ID」，CNV-02 的一一对应关系始终成立。

### F-010 分镜生成（分镜成品 / 分镜表，可导出）

- **输入**：分镜条目（F-005）+ 关联关键帧（F-007）+ 生效提示词（F-004 锚点、F-008 锁定负面词、单条词）。
- **处理**：按镜号顺序把三者组装为分镜成品条目；提供分镜表视图与导出。
- **输出**：分镜成品列表（每条含 镜号、画面描述、关键帧图引用、对白、时长、最终正向词、最终负面词、关联锚点标识）+ 可下载的分镜表文件。
- **关键规则**： 产出的成品条数 == 输入分镜条目数；顺序与镜号一致。 每条成品的最终负面词必须包含锁定全局负面词；最终正向词必须包含关联角色的锁定锚点（无有效锚点时按 ANC-04 标记）。 关键帧缺失的条目以「缺失帧」占位标记呈现，不阻断导出，不伪造图片。 导出文件内容包含全部成品条目的上述字段，且为可读取的结构化/表格格式，不含 API Key（K-02）。

### F-011 视频整合

- **输入**：分镜成品列表（F-010）+ 关键帧引用 + 导出配置参数。
- **处理**：按镜号顺序编排片段，生成片段清单与导出配置；提供应用内顺序预览；导出结构化文件。
- **输出**：片段清单、导出配置、应用内顺序预览、可下载的结构化文件（JSON 或 CSV）与工程包。
- **关键规则**： **【强制规则 · VID-01｜编排】** 片段顺序默认等于分镜镜号升序；**片段数 == 分镜成品条数**。片段字段固定为：顺序号、分镜ID、关键帧引用、时长、转场类型、画面说明。 **【强制规则 · VID-02｜可交付物】** 本轮「整合」的可交付物限定为四项：① 片段清单；② 导出配置（帧率、分辨率、输出命名规则、片段顺序、默认转场类型）；③ 应用内按片段顺序的逐段顺序预览（可前进/后退）；④ 结构化文件与工程包导出。 **【强制规则 · VID-03｜交付边界】** 在「浏览器可运行 + 无需付费服务」约束下，本轮**不产出真实视频编码文件（mp4 / webm 等）、不做音画合成、不合并音频、不产出可直接上传平台的成片**。「整合」定义为**结构化编排**，不是编码。UI 与文案不得出现「导出视频 / 生成成片」等暗示真实编码的表述。 **【强制规则 · VID-04｜与架构解耦】** 若 Phase 3 架构师论证并引入本地编码能力，属能力增强，不改变本轮验收边界（本轮验收仅针对 VID-02）；本说明书不预设架构结论。 **【强制规则 · VID-05｜可交接】** 片段清单与导出配置为结构化、字段完整、无私有二进制，可被第三方剪辑工具读取；导出文件不含 API Key。

## 6. 模型适配层需求

### 6.1 三类模型来源与用途（统一可配置适配层，一套实现）

| 来源类型 | 用途 | 覆盖功能 |
| --- | --- | --- |
| agnes-ai 文本模型 | 剧本生成、剧本拆分、资产提取、分镜脚本生成、提示词相关文本处理 | F-001、F-002、F-003、F-005 |
| agnes-ai 媒体模型 | 资产/场景图片生成、关键帧生成 | F-006、F-007 |
| 自定义模型 | 由创建者指定用途为文本或媒体，按 Base URL + API Key 接入 | 按用途覆盖上述对应功能 |

> 三类来源共用同一套「调用 → 生成任务 → 结果/降级」流程，不按模块重复实现调用逻辑（G-1）。

### 6.2 配置项

| 配置项 | 说明 | 约束 |
| --- | --- | --- |
| 来源类型 | agnes-ai 文本 / agnes-ai 媒体 / 自定义 | 必填 |
| 用途 | 文本 / 媒体 | 必填，决定该配置被哪类任务选用 |
| Base URL | 自定义模型必填 | 仅向该地址发起请求（K-01） |
| API Key | 自定义模型必填 | 本地保存、默认掩码展示（K-01/K-03） |
| 模型名称 / ID | 指定具体模型 | 必填 |
| 超时阈值 | 单次请求超时 | 默认 30 秒，可配置 5~120 秒 `[假设 A-05]` |
| 启用状态 | 是否参与调用 | 关闭时按未配置处理 |
| 强制使用演示数据 | 全局开关 | 开启后忽略全部真实配置 |

### 6.3 降级到演示数据的规则

| 编号 | 规则 |
| --- | --- |
| D-01 | 调用优先级：**已配置且可用的真实来源 > 演示数据**。仅当「未配置 / 未启用 / 鉴权失败 / 超时 / 服务端报错 / 网络中断 / 响应格式非法」时降级 |
| D-02 | 降级**必须可见**：任务状态标 `已降级(演示数据)`，结果预览带「演示数据」标识，不得伪装为真实模型输出 |
| D-03 | 降级**不阻断**：任一模块生成失败均可继续后续流程，主链路不中断 |
| D-04 | 内置演示数据为**固定可复现样例**，覆盖 11 个模块的全部生成类操作，无需联网 `[假设 A-09]` |
| D-05 | 提供全局开关「强制使用演示数据」；开启后忽略真实配置便于离线体验，关闭后恢复 D-01 |
| D-06 | 失败任务支持手动重试；重试成功转 `成功`，仍失败保持 `失败/已降级`；重试**不重复插入重复产物**（幂等） |

### 6.4 错误与超时处理

| 错误类型 | 期望表现 |
| --- | --- |
| 鉴权失败（401/403） | 展示「密钥无效或权限不足，请检查模型配置」，降级到演示数据，不阻断流程 |
| 限流（429） | 展示限流提示，降级到演示数据，允许稍后重试 |
| 服务端错误（5xx） | 展示可读错误信息，降级到演示数据，可重试 |
| 网络中断 | 展示「网络连接不可用」，降级到演示数据 |
| 请求超时 | 达到配置阈值即终止等待，按 D-01 降级，任务记录耗时与超时标记，不无限挂起 |
| 响应格式非法 | 不写入脏数据，按 D-01 降级并标记来源为演示数据 |

所有错误均写入 GenTask 的「错误信息」字段，界面展示可读文案，不展示原始堆栈给非工程师用户。

### 6.5 密钥与数据安全（需求级，实现归 Phase 3）

| 编号 | 要求 |
| --- | --- |
| K-01 | API Key 仅保存在本地模型配置中，仅向创建者填写的目标 Base URL 发送请求，不发送到任何其他地址 |
| K-02 | 工程导出/分享前自动剥离 API Key；导出内容（分镜表、片段清单、工程包）不含任何密钥字段 |
| K-03 | 密钥不写入日志、不写入演示数据、不写入任何导出物；界面展示默认掩码 |
| K-04 | 剧本文本、资产、图片、工程数据仅存本地，不上传第三方，创作者本地数据不外泄（R-04） |
| K-05 | 具体加密与存储实现由架构师 Phase 3 决定，本说明书不选型 |

### 6.6 生成任务状态机（冻结）

  ```
  待处理 → 进行中 → 成功
                  → 失败      → (重试) → 进行中
                  → 已降级(演示数据) → (重试) → 进行中
  ```

任务须记录：状态、耗时、错误信息、重试次数、来源模型标识、最终提示词快照。最终提示词快照是 ANC/NEG 两类强制规则的**唯一可判定依据**。

| E-14 | F-009 | 画布已有节点时重复提交同一指令 / 提交无法识别的指令 | 前者确认后全量重建、节点数仍等于数据源条目数；后者节点数不变并列出支持的三种指令格式 |
| E-15 | F-010/F-011 | 部分分镜缺少关键帧时组装分镜表 / 片段清单 | 以「缺失帧」占位标记呈现，不伪造图片，不阻断导出 |
| E-16 | 全局 | 删除已被下游引用的场次 / 资产 / 分镜 | 提示被引用数量与影响范围，一次显式确认后再删除；级联清理关联引用，不产生悬空 ID |
| E-17 | 全局 | 工程数据损坏 / 重新打开时无法解析 | 提示「工程数据损坏」，不覆盖原始数据，提供「新建工程」或「恢复上一次可用数据」选项 |
| E-18 | 全局 | 本地存储容量超限 | 提示容量不足与当前占用，建议导出备份后清理，不静默丢弃数据 |
| E-19 | 全局 | 工程导出时包含密钥字段 | 导出前自动剥离 API Key，导出文件校验不含密钥字段（K-02） |
| E-20 | F-011 | 用户期待导出可直接播放的成片 | 明确显示交付边界说明（VID-03），仅提供片段清单/配置/预览/结构化文件，不提供 mp4 下载 |

## 9. 可判定验收标准

> 判定口径：每条均可由测试人员以「给定 X，当 Y，则 Z」方式客观验证；不含「体验良好 / 流畅 / 友好」类描述。

### F-001 一句话生成剧本 + 导入剧本

- [ ] 给定未配置任何密钥，当输入一句话创意并触发生成，则产出非空剧本文本，且结果标记来源为「演示数据」
- [ ] 给定粘贴一段剧本并确认导入，则工程内剧本文本与粘贴内容逐字一致
- [ ] 给定上传纯文本剧本文件，则导入后剧本文本与文件内容逐字一致
- [ ] 给定创意为空，当点击生成，则不发起请求、不创建空工程，且显示必填提示
- [ ] 给定工程已有剧本，当再次生成或导入，则出现一次覆盖确认，取消时原剧本不变

### F-002 拆分剧本

- [ ] 给定含 N 个场次标记的剧本，当执行「按场次」拆分，则产出 N 个场次条目且序号连续无重复
- [ ] 给定剧本含 M 个集标记，当执行「按集」拆分，则产出 M 个集条目且集号连续
- [ ] 给定拆分结果，当编辑任一场次正文并保存，则重新读取该场次为编辑后的值
- [ ] 给定拆分结果，当删除一个场次，则剩余场次序号重新连续，且无悬空场次ID

### F-003 分解提取资产

- [ ] 给定剧本文本，当执行资产提取，则输出条目均含 类型、名称、来源文本片段 三个字段
- [ ] 给定提取结果，当新增/删除/编辑任一资产并保存，则列表与保存后读取结果一致
- [ ] 给定资产类型集合，则其取值仅为人自定义范围「人物/场景/道具」三类，无其他类型

### F-004 人物锚点锁定

- [ ] 给定为角色 A 建立并锁定锚点（含描述与锚点标识），当生成任一涉及角色 A 的图片/关键帧任务，则该任务最终提示词快照包含锚点描述与锚点标识
- [ ] 给定锚点已锁定，当单条正向词写入与锚点冲突的外貌描述并生成，则快照中锚点描述生效、冲突描述被标记为「被锚点覆盖」
- [ ] 给定角色 A 锚点已解锁，当新建生成任务，则快照不再强制携带该锚点标识
- [ ] 给定角色无锚点，当生成引用该角色的任务，则显示缺失提示与缺失清单，且任务可成功产出结果
- [ ] 给定锁定锚点后已生成产物，当编辑锚点文本，则已生成产物内容不变（不回溯）
- [ ] 给定一个锁定锚点的生成任务，当查看其最终负面词，则该负面词仍完整包含全部全局锁定词（与 ANC 并行生效）

### F-005 分镜脚本

- [ ] 给定 1 个场次，当生成分镜脚本，则产出 ≥1 条分镜条目，且每条含 镜号、景别、运镜、画面描述、对白、时长 六个非空字段
- [ ] 给定同一场次的分镜条目，则镜号在场次内唯一且升序
- [ ] 给定分镜条目，当修改任一字段并保存，则重新读取为修改后的值

### F-006 图片生成

- [ ] 给定未配置媒体密钥，当触发生成资产图，则产出结果预览，且任务状态标记为「已降级(演示数据)」
- [ ] 给定任一生成任务，当处于进行中，则状态显示「进行中」；结束后状态为「成功」「失败」或「已降级」三者之一
- [ ] 给定生成结果，则可见缩略预览，且可追溯到所属资产/场景ID
- [ ] 给定同一对象任务进行中，当再次点击生成，则不新增第二个任务

### F-007 关键帧生成

- [ ] 给定 1 条分镜，当生成关键帧，则默认产出首帧与尾帧各 1 张，且均关联到该分镜ID
- [ ] 给定任一关键帧任务，当查看最终提示词快照，则其正向词包含该分镜关联角色的锁定锚点、负面词包含全部锁定全局负面词
- [ ] 给定关键帧生成失败/降级，当执行 F-010 分镜生成，则分镜表可正常产出且该条目标记「缺失帧」

### F-008 提示词

- [ ] 给定全局负面词已锁定，当创建任一生成任务，则该任务最终负面提示词包含全部锁定词
- [ ] 给定全局负面词已锁定，当单条任务声明移除某锁定词并生成，则该锁定词仍出现在最终负面提示词中，且操作被拒绝并提示
- [ ] 给定锁定状态，当单条任务追加自身负面词，则最终负面词为锁定词与单条词的并集且无重复项
- [ ] 给定执行「解锁」并确认，当创建新任务，则该任务不再自动附加原锁定词；历史产物不变
- [ ] 给定任一生成任务，则可查看「最终提示词快照」，其中含正向词、负面词与来源标记三项

### F-009 画布生成

- [ ] 给定当前集有 M 个场次，当在画布对话框提交「按场次生成」，则画布节点数 == M，且每个节点关联到唯一场次ID、顺序按场次序号升序
- [ ] 给定有 K 条分镜，当提交「按分镜生成」，则节点数 == K，且节点按镜号升序排列
- [ ] 给定有 L 个资产，当提交「按资产生成」，则节点数 == L，且按资产类别分组、组内按创建序
- [ ] 给定数据源为空，当提交任一自动生成指令，则节点数 == 0，且显示「数据源为空」及缺失原因
- [ ] 给定画布已有自动创建节点，当再次提交同一指令并确认，则节点数仍等于数据源条目数，无重复堆叠节点
- [ ] 给定提交无法识别的指令，则节点数不变，且显示支持的三种指令格式
- [ ] 给定画布节点，当编辑标题或拖动位置，则该节点的「关联数据ID」保持不变

### F-010 分镜生成

- [ ] 给定 N 条分镜且均有关联关键帧与生效提示词，当执行分镜生成，则产出 N 条分镜成品，顺序与镜号一致
- [ ] 给定任一分镜成品，则其字段含 画面描述、关键帧图引用、对白、时长、最终正向词、最终负面词、关联锚点标识
- [ ] 给定任一分镜成品，则其最终负面词包含全部锁定全局负面词、最终正向词包含关联角色锁定锚点
- [ ] 给定分镜表，当执行导出，则生成可下载文件，且文件内容包含全部 N 条成品的上述字段
- [ ] 给定导出文件，当检查其内容，则不含任何 API Key 字段

### F-011 视频整合

- [ ] 给定 N 条分镜成品，当执行视频整合，则产出片段清单，片段数 == N，且顺序号与镜号顺序一致
- [ ] 给定片段清单，当查看导出配置，则可见 帧率、分辨率、输出命名规则、片段顺序、默认转场类型 五项参数
- [ ] 给定片段清单，当执行导出，则生成可下载的结构化文件（JSON 或 CSV），以文本工具打开后字段完整可读
- [ ] 给定片段清单，当在应用内预览，则按片段顺序逐段展示，且展示顺序与清单顺序一致
- [ ] 给定整合产物集合，当检查导出物，则不存在 mp4/webm 等真实视频编码文件，且界面无「导出视频/生成成片」类表述

### 9.12 全局与模型适配层补充验收

- [ ] 给定不配置任何 API Key，当从空白工程连续执行至导出片段清单，则主链路全程可完成，不依赖外部工具与付费服务（S-02）
- [ ] 给定 11 个模块的生成类操作，当逐一在未配置密钥下触发，则 11/11 均返回结果且标记为演示数据
- [ ] 给定开启「强制使用演示数据」，当已配置真实密钥仍触发生成，则任务来源标记为「演示数据」且未向 Base URL 发起请求
- [ ] 给定模型超时或 5xx 报错，当任务结束，则状态为「失败」或「已降级」、错误信息可读，且后续流程可继续
- [ ] 给定工程保存后重新打开，则第 5 章 11 类数据对象条目数与保存前差异为 0（S-03）
- [ ] 给定工程导出文件，当检索密钥字段，则结果为空（K-02）
- [ ] 给定接口与数据模型，当对照第 4 章【强制规则】与第 5 章对象表，则字段名与规则语义一致，无偏离（G-3）

## 附录 A 术语表

| 术语 | 定义 |
| --- | --- |
| 剧本项目 | 一次创作的全部数据与配置的容器，可保存/恢复/导出（R-03） |

| 资产锚点 | 为角色建立的外貌/服装/特征描述、锚点标识与参考图的集合，锁定后强制携带（F-004） |
| 锁定 | 二值状态（未锁定/已锁定）；锁定后规则对**此后新发起**的生成任务生效，不回溯历史产物 |

| 演示数据 / 降级 | 未配置或模型不可用时使用的内置固定样例；必须显式标注来源（D-02） |
| 片段清单 | F-011 产出的按镜号顺序编排的结构化清单，非视频文件 |
| 整合 | 本轮限定为结构化编排（清单 + 配置 + 顺序预览），不含真实视频编码（VID-03） |
