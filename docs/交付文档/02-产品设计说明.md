## 1. 设计目标与信息架构（IA）

### 1.1 形态与目标

- 交付形态为**单页工作台（SPA 壳层 + 主工作区视图切换）**：无登录页、无注册页、无账号页、无整页跳转。打开应用即进入一个「剧本项目」上下文，空白工程直接落在 P-001（步骤 1），不需要先建工程、不需要先选模板。
- 11 个模块全部为**可交互工作区页面**，无静态占位页、无「敬请期待」（S-01）。
- 可判定目标：创作者在**零 API Key** 条件下，从空白工程沿步骤 1→12 连续操作至下载片段清单，全程不切换外部工具（S-02）。
- 数据层级固定 **剧本项目 \> 集 \> 场次 \> 分镜 \> 关键帧**；「场景」= 「场次」；「分镜脚本」(F-005) 与「分镜成品」(F-010) 是两个不同对象，界面上永不合并为一张表。

### 1.2 壳层常驻与 11 模块入口组织

| 项 | 规格 |
| --- | --- |
| 常驻壳层 | 顶部工程栏、左侧步骤导航、底部/全局状态区三块常驻；切换步骤只替换右侧主工作区内容 |
| 模块入口载体 | 左侧步骤导航共 **12 个条目**：11 条对应 11 个模块页面，步骤 2「模型准备」对应全局模型配置抽屉 M-001（需求第 3 章标为可选、贯穿，非独立模块） |
| 导航项内容 | `步骤序号`（两位）+ `步骤名` + `功能ID 徽标` + `状态点` + 已完成时的 `产出计数`；高 40px |
| 主链路顺序 | 条目自上而下严格按 **1→12** 排列，序号不可拖动重排；相邻项间 1px 单向竖线连线。步骤顺序取自需求第 3 章「按实际数据依赖排列」，与功能编号顺序不一致（F-008 在步 6、F-005 在步 7） |
| 状态点四值 | `未开始`（空心）/ `进行中`（强调色实心）/ `已完成`（勾）/ `可跳过`（虚线圈）；由该步是否已产出对应数据对象自动判定，只读 |

### 1.4 跨模块跳转不丢数据

1. 全应用只持有**一个 Project 引用**；切换步骤 = 切换主工作区视图，不重建、不重新加载工程对象。
2. 允许**任意跳转**：点击任一导航项均可进入，**不硬禁用**。前置未满足时目标页显示「前置空态」+ 缺失项 +「前往 P-00X」按钮，不拦截、不弹阻断框。
3. 所有可编辑表格行 `EditableRow` 采用**失焦即写回**；切换视图前不依赖「保存」按钮，重新进入读到写回后的值。
4. 页内未提交的多行文本框在失焦或切换步骤时自动暂存到 Project 对应字段，顶部保存状态追加 `· 有未保存更改`，不静默丢弃。
5. 工程名、提示词组、锚点、模型配置等全局对象由壳层持有，任何页面不持有副本。
6. 覆盖、删除、解锁、全量重建统一走 `ConfirmModal`，取消时原数据不变。

> 【为什么】跨模块不丢数据不能靠「离开前弹保存确认」实现：单人非工程师创作者频繁确认会打断 12 步连续链路，且 S-02 要求一次连续走通。故用失焦即写回 + 单一 Project 引用。

## 2. 全局布局与壳层规格

### 2.1 壳层分区、桌面最小宽度与滚动策略

| 分区 | 位置 | 尺寸 | 随步骤切换 |
| --- | --- | --- | --- |
| 顶部工程栏 | 视口顶部满宽 | 高 56px，固定不滚动 | 否 |
| 左侧步骤导航 | 顶部栏下方左侧固定 | 宽 232px，纵向独立滚动 | 否 |
| 右侧主工作区 | 导航右侧 | 剩余宽度；最小内容宽 960px | 是 |
| 底部/全局状态区 | 视口底部满宽 | 折叠条高 36px；展开面板高 320px | 否 |
| M-001 模型配置抽屉 | 右侧滑出覆盖主工作区右 480px | 宽 480px，全高 | 否 |

- **桌面最小宽度 1280px**。低于 1280px：左侧导航收窄为 64px 图标+序号条（步骤名以 tooltip 呈现），主工作区不压缩字段列，改由表格横向滚动承载；低于 1024px 显示常驻提示条「本工作台面向桌面浏览器，建议窗口宽度 ≥1280px」，功能仍可用（A-10 仅保证桌面主流程）。
- **滚动策略**：壳层三块固定不随内容滚动；主工作区**整区纵向独立滚动**；工作区内表格超出时表格自身横向滚动、表头吸顶；P-009 画布区独立双向平移+缩放，不触发主工作区滚动。主操作按钮（生成/组装/导出）置于区块顶部操作条并**区块内吸顶**，滚动时始终可见。

### P-001 创意与剧本（F-001 · 步骤 1）

**目标与前置**：产出非空 `Project.剧本原文` 并标记 `剧本来源`；无前置，全链路起点。生成/导入两条入口共用同一个 Project，不做两份工程。

**区块划分**

## 7. 视觉与交互基调

> 面向非工程师创作者的**深色专业工作台**：深色底 + 单一强调色；信息密度高但不拥挤；所有状态用第 5 章组件统一呈现。以下仅为色彩与字号层级建议，不含 CSS。

### 7.1 色彩层级建议

| 层级 | 建议色值 | 用途 |
| --- | --- | --- |
| 应用底 | `#0F1115` | 视口底色 |
| 面板 / 导航 | `#171A21` | 顶部工程栏、左侧导航、底部状态区 |
| 卡片 / 表头 | `#1E222B` | SectionCard、DataTable 表头、节点卡片 |
| 悬浮 / 输入 | `#262B36` | 输入框、下拉、悬浮行 |
| 边框 | `#2F3542` | 1px 分隔线、卡片描边 |
| 主文本 | `#E8EAF0` | 标题、正文、表格内容 |
| 次文本 | `#A8B0C0` | 字段标签、辅助说明 |
| 弱文本 | `#6B7385` | 只读 ID、时间戳、占位符 |
| **单一强调色** | `#4C8DFF` | 当前步骤、主按钮、选中态、焦点环、画布连线、链接；弱态用其 12%\~20% 透明度作背景 |

**状态语义色**（仅用于 C-03 `StatusTag` 的文字与 1px 描边，低饱和，不做大面积填充，**不视为第二强调色**）：成功 `#3FBF7F`、警告 `#E8B04B`、危险 `#E5615E`、信息 `#7F8CA3`。

**演示数据标识不使用独立彩色**：统一为「中性灰底 + 斜纹 + `演示数据` 文字」（7.5），避免破坏单一强调色基调。

### 7.2 字号与信息层级

| 层级 | 建议字号 / 字重 | 示例 |
| --- | --- | --- |
| L1 页面标题 | 20px / 600 | `步骤 11 / 12 · 分镜生成 · F-010` |

信息层级固定为：页面标题 \> 区块标题 \> 表头 \> 正文 \> 辅助；同一页面内不出现两个 L1。

### 7.3 密度

- 表格行高 36~~40px，控件高 32px，区块间距 16px，卡片内边距 12~~16px。
- 主操作按钮（生成 / 组装 / 导出 / 发送）置于区块顶部操作条并**区块内吸顶**，滚动时始终可见；不做全屏浮层按钮。
- 只读 ID、时间戳不占用主列，收敛为尾码 + tooltip 或可展开行。
- 一屏内优先保证「数据 + 主操作 + 状态」三者同时可见；长文本（剧本原文、最终提示词）用可展开行 / 只读区承载，不铺满整屏。
